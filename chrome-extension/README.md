# Perdix Brain - Chrome Extension Prototype

Esta es la extensión que rastrea tu "Cognitive Output" en segundo plano.

## 🚀 Cómo Instalar (Modo Desarrollador)

1.  Abre Google Chrome.
2.  Escribe en la barra de direcciones: `chrome://extensions/`
3.  Activa el interruptor **"Modo de desarrollador"** (arriba a la derecha).
4.  Haz clic en el botón **"Cargar descomprimida"** (Load unpacked).
5.  Selecciona la carpeta:
    `C:\Users\Erick Zambrano\Desktop\linkedin\PROYECTOS\ingenieria-platform\chrome-extension`

## 🧪 Cómo Probar

1.  Ve a `https://chatgpt.com` o `https://gemini.google.com`.
2.  Empieza a escribir.
3.  Abre la consola de la extensión (clic en el icono de rompecabezas > Perdix Brain > Inspeccionar pop-up o background) para ver los logs de "Tokens Detectados".

**Nota:** Esta versión es silenciosa. No muestra nada en pantalla para no molestar, pero registra los datos internamente.
