# Demostración de Skills en Ingeniería Platform

¡Bienvenido! Las skills (habilidades) de IA ahora están activas en esta carpeta.

Para probar que todo funciona, abre el chat con tu Agente de IA y pregúntale:

> "Usa la habilidad 'algorithmic-art' para crear un diseño simple"
> O simplemente: "¿Qué habilidades tienes disponibles aquí?"

Tus skills se cargan automáticamente desde `Desktop\linkedin\PROYECTOS\.skills`.
Disfruta de tu "Súper Agente" en este proyecto.
